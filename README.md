# Facharbeit – Seminarfachkurs Glück

> *Wie Schule wirkt: Strukturelle Unterschiede und ihr Effekt auf das
> Wohlbefinden von Schülerinnen und Schülern* (Svea Timphus, Gymnasium Damme,
> 2026)

## Inhalt dieses Repositories

- `praesentation/` – Keynote-Style-Präsentation zur Facharbeit
  - `Wie_Schule_wirkt.pptx` – fertige Präsentation für Keynote (iPad/Mac)
  - `Wie_Schule_wirkt.pdf` – PDF-Vorschau
  - `preview/` – Bilder der einzelnen Folien
  - `build_presentation.py` – Generator-Skript (`python-pptx`)
  - `README.md` – Anleitung für Keynote-Import, Übergänge und Animationen

Die Präsentation basiert ausschließlich auf der Facharbeit. Es werden keine
zusätzlichen Inhalte oder Statistiken hinzugefügt.
