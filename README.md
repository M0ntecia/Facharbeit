# Facharbeit

Dieses Repository enthält eine auf Grundlage der Facharbeit erzeugte Präsentation im Keynote-Style.

## Ausgabe

- Präsentation: `output/Wie_Schule_wirkt_Keynote_Style.pptx`
- Moderationsnotizen: `output/Moderationsnotizen.md`

## Neu erzeugen

```bash
npm install
npm run build
```

Die Präsentation wird als `.pptx` erzeugt und kann auf dem iPad in Keynote importiert werden.
