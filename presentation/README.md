# Keynote-kompatible Präsentation

Datei: `Schule_Wohlbefinden_Keynote_Style.pptx`

Die Präsentation ist für den Import in Apple Keynote auf dem iPad angelegt. Inhalte, Folienstruktur und Sprechnotizen basieren ausschließlich auf der bereitgestellten Facharbeit.

Gewünschte Folienübergänge:
1. Fade
2. Zoom
3. Move In
4. Magic Move
5. Scale
6. Push
7. Dissolve
8. Pop
9. Slide
10. Rotate
11. Fade

Hinweis: Einige Keynote-spezifische Übergänge werden in PPTX-kompatibler Form angenähert und können nach dem Import in Keynote bei Bedarf exakt auf den genannten Effekt gestellt werden.
